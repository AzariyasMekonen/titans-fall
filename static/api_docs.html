Kronos Analytics Engine - API Reference

Version 4.2.1 | Internal Use Only

⚠ All endpoints require Bearer JWT authentication with valid organizational claims (tid, aud, appid, upn). See /swagger.json for the full OpenAPI specification.

Endpoints

GET /v1/GetConfig
Returns the current service configuration. Requires Admin role.
GET /v1/GetTables?routingTarget={target}
Lists all tables available for the specified routing target.
POST /v2/Query
Executes a raw SQL query against the specified routing target. Requires Admin role. Body: {"routingTarget": "...", "query": "..."}
POST /v1/Insert
Insert data record. Currently disabled in production (HTTP 503).

Authentication

Obtain a valid JWT from your organization's identity provider. The token must include the following claims:

  • tid - Tenant ID
  • aud - Audience (this service's identifier)
  • appid - Registered Application ID
  • upn - User Principal Name
